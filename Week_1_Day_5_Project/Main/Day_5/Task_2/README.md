# Employee Data Analysis — Week 1 Day 5

A practice project analyzing 10 synthetic employee records with Python.

## Tools
Python, Pandas, Matplotlib, Seaborn, Jupyter, nbconvert.

## Folder contents
- `Task_1/employee_data.csv`: dataset
- `Task_1/employee_analysis.ipynb`: analysis notebook
- `Task_1/figures/`: chart PNGs
- `Task_1/requirements.txt`: dependencies
- `Task_2/report.md`: one-page findings report
- `Task_2/employee_analysis.html`: exported report

## Run
1. Open the `Day_5` folder in VS Code.
2. In terminal, move into Task 1: `cd Task_1`
3. Install: `python -m pip install -r requirements.txt`
4. Start notebook: `jupyter notebook` (or open the `.ipynb` in VS Code)
5. Open `employee_analysis.ipynb` and choose **Run All**.

Charts are saved under `Task_1/figures/`.
